# 岗位转型导师

一个面向轨道交通工程建设人员的 AI 导师 Skill，帮助学员把建设经验带入运营岗位，并在岗位学习、协同交接和日常复盘中找到具体的下一步。

## 它能帮助你做什么

- 梳理过去的工程经历，找到与新岗位有关的能力。
- 理清新任务需要交接的信息和协同对象。
- 将经验整理为简短的学习或沟通提醒，并请同事试用。
- 观察工作中的变化，区分事实与推测，准备向专业同事请教的问题。

导师的方法参考阿图·葛文德的《清单革命》，以及卡尔·E·威克、凯瑟琳·M·萨特克利夫的《应急管理：如何确保尖峰时刻的高效运作》。知识经过定向整理；不需要拥有原著即可使用。书中方法被迁移到岗位转型场景时，属于本 Skill 的应用建议。

## 获取与安装

下载本仓库完整文件，保留 `SKILL.md`、`references/` 和 `resources/` 的目录结构。不要只复制 `SKILL.md`，否则导师无法读取能力卡和书籍依据。

使用 Git 的学员可以在终端运行：

```bash
git clone https://github.com/Atange2023/rail-transition-mentor.git
```

将下载得到的 `rail-transition-mentor` 文件夹按所使用 AI 助手的 Skill 安装方式导入或复制。不同产品的安装方法各不相同；如果产品不支持 Skill 导入，可将整个文件夹交给支持读取本地文件的 AI 助手，并要求它先读取 `SKILL.md`。不要上传未经单位许可的内部资料。

## 开始试用

可以先这样问：

> 我原本负责轨道工程建设，现在准备转到车站运营岗位。请帮我想想，过去的哪些经验可能有用，第一周应该从哪里开始？

还可以问：

- “我原来做设备交接，现在需要和站务人员协作，该怎么把信息讲清楚？”
- “我准备跟班学习，怎样整理一张简短的观察和交接提醒？”
- “我发现一个反复出现的小问题，应该怎样请同事一起分析？”

导师会先了解你的情况，再结合已有材料给出建议。你也可以指出回答中不符合实际的地方，要求它调整。

## 使用范围

本 Skill 用于学习、经验迁移和团队沟通；它不替代正式岗位规程、授权决策和专业培训。涉及正在发生的紧急情况，应按所在单位现行程序联系授权岗位。此版本基于两本书中已核对的相关内容定向整理，并非两书的完整复现；仓库不包含原书全文。
